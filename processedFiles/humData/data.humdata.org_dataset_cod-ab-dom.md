# Dominican Republic - Subnational Administrative Boundaries

Get Notified


[Unsubscribe](https://data.humdata.org/dataset/cod-ab-dom# "Unsubscribe")

Dominican Republic administrative level 0-4 boundaries (COD-AB) dataset version 01.

This dataset is structured into 4 levels:

\- Admin 1: 10 region

\- Admin 2: 32 province or national district (distrito nacional)

\- Admin 3: 155 municipio

\- Admin 4: 386 dm(?)

Dates associated with this dataset:

\- 17 February 2025: dataset reviewed for accuracy and completeness

\- 29 June 2021: valid for use by the humanitarian community

\- 06 September 2017: last edit to the dataset before publishing

\- 06 September 2017: boundaries created by the source

Quality assured, configured, and published by [OCHA Field Information Services (FIS)](https://data.humdata.org/organization/ocha-fiss) and [HDX](https://data.humdata.org/organization/hdx).

Part of the dataset: [Global Subnational Administrative Boundaries](https://data.humdata.org/dataset/cod-ab-global)
